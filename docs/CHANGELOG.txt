v1.0.0  (2026-06-03)  — 최초 릴리스
────────────────────────────────────────────────────────────────
[성능 최적화]
  - 클립 병렬 추출: Promise.all로 전체 클립 동시 추출 (~5배 속도 향상)
  - ffmpeg spawnSync → async spawn으로 전환 (이벤트 루프 블로킹 제거)
  - CRC32 테이블 모듈 로드 시 1회 계산으로 최적화
  - extractAudio await 누락 버그 수정

[기능]
  - AI 장면 분석 (Gemini 2.5 Flash)
    · AI 역할 프리셋: 예능 PD / 드라마 편집자 / MZ 쇼츠 전문가 / 스포츠 하이라이터
    · 타겟 시청자 설정 (7개 프리셋 + 직접 입력)
    · 장면 묘사 힌트 / 유형 선택 (8가지)
  - 추출 설정: 클립 개수(3/5/7/10) / 최소 길이(30초~3분) / 출력 포맷
  - 클립 추출 및 ZIP 다운로드 (ffmpeg)
  - 썸네일 자동 추출 (클립당 JPG, ZIP 포함)
  - SRT 자막 파일 생성 (캡컷 import용)
  - 포인트 자막 가이드 (TXT + SRT)
  - 재분석: 이전 장면 제외하고 새 장면 탐색
  - 분석 결과 score 배지 (⭐ N/10 바이럴 가능성)
  - 세로 변환 9:16 (블러 배경 오버레이)
  - 기록 저장/불러오기 (localStorage, 최대 20개)
  - 수동 클립 추가
