================================================================
  Clip Extractor — Electron EXE 빌드 및 실행 방법
================================================================

────────────────────────────────────────────────────────────────
빌드 전 요구 사항
────────────────────────────────────────────────────────────────

  - Node.js 18 이상
  - npm 패키지 설치 완료 (npm install)
  - 인터넷 연결 (electron 바이너리 다운로드)


────────────────────────────────────────────────────────────────
빌드 (EXE 생성)
────────────────────────────────────────────────────────────────

  npm run electron:build

  내부적으로 아래 세 단계가 순서대로 실행됩니다:

    1. next build
       Next.js 프로덕션 빌드 + .next/standalone 생성

    2. node scripts/prepare-electron.js
       .next/static  →  .next/standalone/.next/static  복사
       public/       →  .next/standalone/public/        복사

    3. electron-builder
       Windows NSIS 인스톨러 생성


────────────────────────────────────────────────────────────────
빌드 결과물
────────────────────────────────────────────────────────────────

  dist-electron/
  ├── Clip Extractor Setup 1.0.0.exe   ← 인스톨러 (배포용)
  └── win-unpacked/
      └── Clip Extractor.exe           ← 포터블 (설치 없이 실행)

  배포 시: Setup.exe 하나만 전달
  개인 사용: win-unpacked 폴더째로 원하는 위치에 복사 후 실행


────────────────────────────────────────────────────────────────
첫 실행 흐름
────────────────────────────────────────────────────────────────

  Clip Extractor Setup 1.0.0.exe 실행
    → 설치 마법사 진행
    → 바탕화면 / 시작 메뉴에 단축키 생성

  앱 첫 실행
    → API 키 입력 화면 (첫 번째만)
    → Google AI API 키 입력 (AIzaSy... 형식)
    → 시작하기 클릭
    → 키가 AppData에 저장됨
    → 로딩 화면 (서버 시작 중)
    → 메인 화면

  두 번째~ 실행
    → 로딩 화면 → 메인 화면 (API 키 입력 없음)


────────────────────────────────────────────────────────────────
API 키 얻는 방법
────────────────────────────────────────────────────────────────

  1. https://aistudio.google.com/app/apikey 접속
  2. Google 계정으로 로그인
  3. [Create API key] 클릭
  4. 생성된 키 복사 (AIzaSy... 형식)
  5. Clip Extractor 초기 설정 화면에 붙여넣기


────────────────────────────────────────────────────────────────
API 키 변경 / 재설정
────────────────────────────────────────────────────────────────

  아래 파일을 삭제하면 다음 실행 시 설정 화면이 다시 표시됩니다.

  경로:
    C:\Users\[사용자명]\AppData\Roaming\Clip Extractor\config.json

  (AppData 폴더가 안 보이면 탐색기 주소창에 %APPDATA% 입력)


────────────────────────────────────────────────────────────────
개발 모드 실행 (EXE 없이 테스트)
────────────────────────────────────────────────────────────────

  npm run electron:dev

  Next.js 개발 서버 + Electron 창이 동시에 실행됩니다.
  개발 중 코드 변경 사항이 실시간으로 반영됩니다.
  단, API 키는 .env.local 파일에 설정되어 있어야 합니다.

  .env.local 내용:
    GOOGLE_AI_API_KEY=AIzaSy...


────────────────────────────────────────────────────────────────
구조 설명
────────────────────────────────────────────────────────────────

  electron/
    main.js        메인 프로세스
                   - API 키 config.json 읽기/쓰기
                   - Next.js 서버 실행 (utilityProcess.fork)
                   - 설정 창 / 로딩 창 / 메인 창 관리
    preload.js     렌더러 ↔ 메인 IPC 브릿지
    setup.html     API 키 입력 화면 UI

  scripts/
    prepare-electron.js  빌드 전처리 (파일 복사)

  electron-builder.yml   인스톨러 설정
  next.config.ts         standalone 출력 모드 활성화


────────────────────────────────────────────────────────────────
트러블슈팅
────────────────────────────────────────────────────────────────

  [앱이 흰 화면으로 멈춤]
    → Next.js 서버가 아직 시작 중입니다. 잠시 기다리세요.
    → 로딩 창이 닫히면 서버 준비 완료입니다.

  [API 키 오류]
    → config.json 삭제 후 재실행하여 키 재입력

  [빌드 실패: .next/standalone 없음]
    → npm run build 를 먼저 실행해야 합니다.

  [electron 다운로드 실패]
    → 네트워크 연결 확인 또는 npm install 재실행
