────────────────────────────────────────────────────────────────
권장 사용 순서
────────────────────────────────────────────────────────────────

  ① AI 역할 설정
  ② 타겟 시청자 설정
  ③ 영상 파일 선택
  ④ (선택) 찾고 싶은 장면 묘사 / 장면 유형 선택
  ⑤ 추출 설정 (클립 개수 · 길이 · 출력 포맷)
  ⑥ AI 분석 시작
     → 결과가 마음에 안 들면 🔄 재분석
  ⑦ 타임스탬프 확인 · 수정
  ⑧ ✍ 포인트 자막 생성 (선택)
  ⑨ ✂ 클립 추출 → ZIP 다운로드


────────────────────────────────────────────────────────────────
1. AI 역할 설정
────────────────────────────────────────────────────────────────

  AI에게 전문가 역할을 부여하면 그 시각으로 장면을 분석합니다.

  [프리셋]
  - 예능 PD       : 웃음 포인트 · 케미 · 반전 위주
  - 드라마 편집자 : 감동 · 눈물 · 명대사 위주
  - MZ 쇼츠 전문가: 바이럴 · 댓글 유발 · 공유 욕구 위주
  - 스포츠 하이라이터: 클라이맥스 · 역전 · 긴장감 위주
  - 직접 입력     : 자유롭게 텍스트로 지정

  [팁]
  같은 영상을 역할만 바꿔 여러 번 분석하면 다른 장면이 잡힙니다.
  역할이 구체적일수록 분석 품질이 높아집니다.


────────────────────────────────────────────────────────────────
2. 타겟 시청자
────────────────────────────────────────────────────────────────

  선택한 시청자의 시각으로 "이 사람이 반응할 장면"을 기준으로 분석합니다.
  같은 영상도 10대 학생과 40~50대 직장인이 선택하는 장면이 다릅니다.

  프리셋: 10대 학생 / 20대 직장인 / 30대 부모 / 40~50대 직장인
          주부 / MZ세대 / 시니어

  직접 입력란에 "30대 육아 맘", "운동을 좋아하는 20대" 등
  구체적으로 입력할수록 분석 결과가 더 정확해집니다.


────────────────────────────────────────────────────────────────
3. 영상 파일
────────────────────────────────────────────────────────────────

  지원 포맷: MP4 · MOV · AVI · MKV · TS · WebM · 기타 대부분의 영상
  용량 제한: 없음 (로컬 처리)

  처리 방식: 영상에서 오디오만 추출하여 AI에 전달
             → 영상 화질과 무관하게 분석 가능
             → 2시간 분량도 단일 분석으로 처리

  예상 소요 시간:
  - 30분 영상 → 약 1~2분
  - 2시간 영상 → 약 3~5분


────────────────────────────────────────────────────────────────
4. 찾고 싶은 장면 묘사 (선택)
────────────────────────────────────────────────────────────────

  AI에게 특정 장면을 우선 찾도록 힌트를 줍니다.
  입력 예시:
  - "두 출연자가 처음 만나는 장면"
  - "클라이맥스에서 눈물 흘리는 장면"
  - "음식 먹는 리액션이 터지는 순간"

  비워두면 AI가 전체 영상에서 자체 판단으로 선정합니다.


────────────────────────────────────────────────────────────────
5. 추출할 장면 유형 (선택)
────────────────────────────────────────────────────────────────

  복수 선택 가능. 미선택 시 전체 유형에서 자동 분석.

  🥺 감동  : 가슴 뭉클 · 눈물 · 훈훈함
  😂 웃음  : 실제로 웃음이 터지는 순간
  😱 반전  : "헉" 하고 예상을 벗어나는 순간
  💬 명대사: 공감되거나 저장하고 싶은 말
  🔥 하이라이트: 긴장감 · 에너지가 가장 높은 클라이맥스
  ✨ 케미  : 출연자 간 매력적인 케미
  ⚡ 열정  : 뜨겁고 자극적인 순간
  📚 정보  : 유익한 정보가 담긴 순간


────────────────────────────────────────────────────────────────
6. 추출 설정
────────────────────────────────────────────────────────────────

  [클립 개수]  3개 / 5개 / 7개 / 10개 선택 (기본값: 5개)
  분석 전에 설정. AI가 해당 개수의 장면을 선정합니다.

  [최소 클립 길이]  30초 / 1분 / 2분 / 3분 (기본값: 2분)
  - AI 프롬프트 가이드라인에 반영
  - 추출 시 최소 길이 강제 적용
  - 쇼츠(60초 이하) 제작 시 1분 이하 권장

  [출력 포맷]
  - 가로 (원본): 영상 원본 비율 그대로 추출
  - 세로 9:16 : Shorts/Reels/TikTok용
                블러 배경 위에 원본 영상을 중앙 오버레이


────────────────────────────────────────────────────────────────
7. 분석 결과 활용
────────────────────────────────────────────────────────────────

  [영상 요약]
  AI가 영상 전체 내용을 2~3줄로 요약합니다.

  [⭐ score 배지]
  각 카드에 쇼츠 바이럴 가능성 점수가 표시됩니다. (1~10)
  10 = 즉시 공유하고 싶은 수준

  [파일명 편집]
  카드 상단 텍스트 입력란에서 추출될 파일명을 수정할 수 있습니다.

  [⏱ 타임스탬프 수정]
  AI가 잡은 시작·끝 시간을 직접 조정할 수 있습니다.
  잘못된 형식이면 빨간색으로 표시됩니다.

  [📥 내보내기]
  전체 장면 정보(시간·훅·해시태그)를 TXT 파일로 저장합니다.

  [✂ 클립 추출]
  - 전체 추출: 체크박스 선택 후 상단 [N개 클립 추출] 클릭
  - 개별 추출: 각 카드의 [이 클립만 추출] 클릭
  - 결과: ZIP 파일 다운로드

  [✂ AI가 놓친 장면 직접 추가]
  결과 하단에서 시작·끝 시간을 직접 입력 후 추출합니다.

  [🔄 재분석]
  결과가 마음에 안 들면 클릭.
  이전에 선정된 장면 시간대를 제외하고 새 장면을 탐색합니다.


────────────────────────────────────────────────────────────────
8. 포인트 자막 가이드 (✍)
────────────────────────────────────────────────────────────────

  각 장면 카드에서 [✍ 포인트 자막] 클릭 시 AI가 해당 구간을
  재분석하여 캡컷 포인트 자막 타이밍과 텍스트를 제안합니다.

  결과 예시:
    00:08 | ㅋㅋㅋ  | 이 부분에서 웃음 터짐
    00:23 | 헐      | 예상 밖 발언에 당황
    01:12 | ...     | 어색한 침묵

  [활용 방법]
  - [복사]         → 클립보드에 복사
  - [📥 TXT 저장] → 가이드용 텍스트 파일
  - [📥 SRT 저장] → 캡컷에 바로 import 가능한 자막 파일

  포인트 자막 생성 후 클립을 추출하면
  ZIP 안에 .txt 와 .srt 파일이 자동으로 포함됩니다.

  캡컷 사용 방법:
    타임라인 → 해당 시간대 이동 → 텍스트 추가 → 0.5~1초 배치

────────────────────────────────────────────────────────────────
10. 기타 기능
────────────────────────────────────────────────────────────────

  [기록]
  분석 완료 시 자동 저장 (최대 20개).
  헤더의 [기록] 버튼으로 이전 분석 결과를 불러올 수 있습니다.
  ※ 기록에서 불러온 결과로 추출 시 영상 파일을 다시 선택해야 합니다.

  [초기화]
  헤더의 [초기화] 버튼으로 전체 상태를 리셋합니다.
  새 영상 분석을 시작할 때 사용합니다.

  [↑ 맨위로]
  스크롤을 내렸을 때 우하단에 버튼이 표시됩니다.

  [브라우저 알림]
  분석 완료 시 브라우저 알림이 옵니다. (알림 허용 필요)

  [취소]
  분석 중 진행률 표시 옆 [취소] 버튼으로 분석을 중단합니다.

  ※ 기록은 이 PC 브라우저에 저장됩니다.
     브라우저 캐시 삭제 시 기록이 사라질 수 있습니다.


────────────────────────────────────────────────────────────────
활용 팁
────────────────────────────────────────────────────────────────

  • 같은 영상을 AI 역할만 바꿔 여러 번 분석하면 다른 장면을 잡습니다.
  • 🔄 재분석을 누르면 이전 장면과 겹치지 않는 새 장면을 찾습니다.
  • 포인트 자막은 추출 전에 생성해야 ZIP에 자동 포함됩니다.
  • 분석 완료 시 브라우저 알림이 옵니다. (알림 허용 필요)
  • 분석 중 취소가 필요하면 진행률 표시 옆 [취소] 버튼을 누르세요.
