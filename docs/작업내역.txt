1. 성능 최적화
────────────────────────────────────────────────────────────────

[클립 병렬 추출]
  - 이전: 클립을 순서대로 하나씩 추출 (5개 선택 시 5배 느림)
  - 개선: Promise.all로 모든 클립 동시 추출
  - 효과: 클립 5개 기준 ~5배 속도 향상
  - 파일: app/api/extract/route.ts

[ffmpeg 비동기 전환]
  - 이전: spawnSync — ffmpeg 실행 중 Node.js 이벤트 루프 완전 차단
  - 개선: spawn + Promise — 비동기 처리
  - 효과: 서버가 ffmpeg 실행 중에도 다른 요청 처리 가능
  - 파일: lib/ffmpeg.ts

[CRC32 테이블 사전 계산]
  - 이전: makeZip 호출마다 256번 루프 계산
  - 개선: 모듈 로드 시 한 번만 계산 후 재사용
  - 파일: lib/zip.ts

[오디오 추출 누락 await 수정]
  - 이전: extractAudio() 앞에 await 없음 → 추출 전에 AI 호출 시도
  - 개선: await 추가로 정상 순서 보장
  - 파일: app/api/analyze/route.ts

4. Electron EXE 빌드 설정
────────────────────────────────────────────────────────────────

[추가된 파일]
  - electron/main.js       Electron 메인 프로세스
  - electron/preload.js    IPC 브릿지 (contextBridge)
  - electron/setup.html    API 키 입력 화면 (첫 실행 시)
  - scripts/prepare-electron.js  빌드 전처리 스크립트
  - electron-builder.yml   Windows NSIS 인스톨러 설정

[수정된 파일]
  - next.config.ts         output: "standalone" 추가
  - package.json           main, electron 의존성, 빌드 스크립트 추가

[배포 방식]
  - 빌드 명령: npm run electron:build
  - 결과물: dist-electron/Clip Extractor Setup 1.0.0.exe (인스톨러)
  - 결과물: dist-electron/win-unpacked/Clip Extractor.exe (포터블)
  - 배포 시 Setup.exe 하나만 전달하면 됨
  - 수신자는 Node.js 불필요, API 키만 직접 입력

[첫 실행 흐름]
  Setup.exe 설치 → 앱 실행 → API 키 입력 화면
  → 키 저장 (AppData\Roaming\Clip Extractor\config.json)
  → 로딩 → 메인 화면

[API 키 재설정]
  AppData\Roaming\Clip Extractor\config.json 삭제 후 재실행
